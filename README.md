# Cinema Seat Management

A backend/API project developed to manage the status of seats in cinema
halls and show users which seats are occupied or available.

The main goal of this project is to learn FastAPI and backend development
concepts. When a user selects a cinema hall and a session (showtime), the
API returns the status of the seats in that hall. In a later stage, seat
reservation will also be supported.

## Tech Stack

- **Python** — main programming language
- **FastAPI** — for building the REST API
- **Pydantic** — for validating data going in/out of the API
- **SQLAlchemy** — for connecting Python to the database (ORM)
- **SQLite** — starter database
- **Uvicorn** — ASGI server used to run the FastAPI app
- **Swagger UI** — for testing the API (auto-generated by FastAPI)

## Architecture

```
Client
  │  HTTP Request
  ▼
FastAPI (routers/)
  │
  ▼
Service Logic (services/)
  │
  ▼
SQLite Database (models.py + database.py)
```

There is no frontend in the first stage — the APIs are tested through
Swagger UI (`/docs`).

## Data Model

- **Hall** — a cinema hall
- **Seat** — a seat belonging to a hall (row, number)
- **Session** — a showtime, i.e. which movie is playing in which hall at
  which time
- **Reservation** — a reservation record for a given session + seat
  combination; if a reservation exists for that combination the seat is
  **occupied**, otherwise it is **available**

## Project Structure

```
cinema-seat-management/
├── models.py           # SQLAlchemy table definitions
├── schemas.py          # Pydantic models
├── routers/            # API endpoints
└── services/            # business logic
```

## Setup

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

## Running

```bash
uvicorn src.main:app --reload
```

Then open `http://127.0.0.1:8000/docs` to test the APIs via Swagger UI.
